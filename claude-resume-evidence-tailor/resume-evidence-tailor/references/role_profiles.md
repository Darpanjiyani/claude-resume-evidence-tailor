# Role Profiles

Use the matching profile to decide what to put first in the Summary, Skills, Experience, and Projects.

## Data Engineer
- Screens for: pipelines, ETL/ELT, scale, reliability, data modeling, cloud, orchestration
- Bullet emphasis: architecture, data volume, latency, reliability, cost or performance optimization
- Skills order: Languages → Data Engineering → Cloud/Warehouses → Modeling → AI → BI
- Put first: Real-Time Ride Analytics (Event Hubs over Kafka, streaming, SCD Type 1 and 2), Transportation Analytics Lakehouse Pipeline (streaming ingestion, CDC, data quality checks), E-Commerce Analytics Platform (legacy migration to a Databricks lakehouse), Real-Time Cryptocurrency Trend Analysis (Kafka, PySpark, EMR), Football Data Analytics (Snowflake star schema), Retail Sales Analytics Platform (dbt tests, SCD Type 2)
- Self-study Airflow goes in Skills only, never as a project

## Data Analyst / BI Analyst
- Screens for: SQL, dashboards, KPIs, stakeholder communication, reporting automation, insights that drive decisions
- Bullet emphasis: who used the output, what decision it supported, time saved, issues surfaced
- Skills order: SQL → BI tools (Power BI, DAX, Tableau) → Python/pandas → Excel → Data Modeling → Engineering
- Summary angle: turning raw data into decisions for business or operations teams

## Business Data Analyst
- Screens for: requirements gathering, process improvement, KPI definition, cross-functional work, documentation
- Bullet emphasis: the business problem, the stakeholders involved, the process changed, the measurable result
- Put first: reporting automation, operator alerting, root-cause analysis, stakeholder partnership

## Data Scientist
- Screens for: statistical modeling, machine learning, forecasting, experimentation, evaluation metrics
- Bullet emphasis: model or method, evaluation metric, baseline comparison, business use
- Put first: ML coursework projects, evaluation frameworks, anomaly detection, rolling baselines
- If no modeling project exists, flag it as a "Fix with a project" gap

## Financial Analyst
- Screens for: financial modeling, forecasting, budgeting, variance analysis, Excel, financial statements
- Treat as a stretch role unless the Evidence Bank shows finance coursework, certifications, or projects
- Put first: cost or time savings stated as money where supported, forecasting work, Excel and SQL reporting
- Warn the user honestly if the core requirements are missing

## AI / ML Engineer
- Screens for: LLMs, fine-tuning (LoRA/QLoRA), RAG, vector databases, model evaluation, deployment (APIs, cloud), MLOps
- Bullet emphasis: model or system built, evaluation metric vs baseline, deployment target, latency or cost
- Skills order: Languages → ML/AI frameworks → LLM tooling (LangChain, RAG, vector stores, MCP) → Cloud/Deployment → Data Engineering
- Put first: MS capstone (fine-tuning, benchmarking, FastAPI on Cloud Run), AI Data Agent (LangGraph agents, text-to-SQL evaluation), Multimodal LLM project, Doodle Recognition
- Self-study AI tools (RAG, MCP, LLM APIs) go in Skills only, never as projects

## Analytics Engineer
- Screens for: dbt, SQL, data modeling (star schema, dimensional), data testing, version control, CI/CD, semantic or BI layers
- Bullet emphasis: models built, tests and data quality, modeling choices, who uses the output
- Skills order: SQL → dbt → Warehouses/Lakehouse (Snowflake, Databricks) → Data Modeling → Python → BI
- Put first: dbt project, Football star schema, Databricks medallion projects

## Software Engineer (secondary only)
- Screens for: backend APIs, frontend frameworks, authentication, testing, containers, event-driven systems
- Bullet emphasis: features shipped, architecture, testing, deployment
- Put first: Food Delivery Platform, Taxi Booking Web App
- These projects are used for data roles only when the JD names Kafka, Docker, Kubernetes or REST APIs
